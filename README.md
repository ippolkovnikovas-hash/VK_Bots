# VK_Bots

Готовый шаблон для создания ботов ВКонтакте на Python с использованием библиотеки `vk_api` и Bots Long Poll API.

## Возможности
- Обработка входящих сообщений через Long Poll API
- Система команд (текстовые команды и клавиатура)
- Приветственное сообщение и клавиатура с кнопками
- Конфигурация через `.env` файл (токен, id группы)
- Простая структура для расширения новыми хендлерами

## Структура проекта
```
VK_Bots/
├── bot.py            # Точка входа, основной цикл Long Poll
├── config.py         # Загрузка конфигурации из .env
├── handlers.py        # Обработчики команд бота
├── keyboards.py       # Генерация клавиатур VK
├── requirements.txt   # Зависимости
├── .env.example       # Пример файла окружения
└── README.md
```

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ippolkovnikovas-hash/VK_Bots.git
cd VK_Bots
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и заполните своими данными:
```bash
cp .env.example .env
```

В `.env` укажите:
- `VK_GROUP_TOKEN` — токен доступа сообщества (Управление сообществом → Работа с API → Ключи доступа)
- `VK_GROUP_ID` — ID вашего сообщества

## Настройка сообщества VK

1. Создайте сообщество (публичную страницу).
2. В настройках включите «Сообщения сообщества».
3. В разделе «Настройки для бота» включите «Возможности ботов».
4. В «Работа с API» → «Ключи доступа» создайте ключ с правами на сообщения.
5. Включите Long Poll API (версия API — последняя доступная), отметьте нужные типы событий (входящие сообщения).

## Запуск

```bash
python bot.py
```

## Доступные команды бота

| Команда   | Описание                        |
|-----------|----------------------------------|
| привет    | Приветствие и показ клавиатуры   |
| помощь    | Список доступных команд          |
| время     | Текущее время сервера            |
| эхо <текст> | Бот повторяет введённый текст  |

## Расширение

Добавляйте новые команды в `handlers.py` в словарь `COMMANDS`, каждая функция принимает объект `vk_api.VkApi` и текст события.
